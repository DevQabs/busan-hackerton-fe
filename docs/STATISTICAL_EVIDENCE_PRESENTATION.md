# 통계 분석 씬(/evidence) — 발표자료 제작 가이드

> **한 줄 요약**: Part 2(접근성 진단 → 해운대 상세)에서 눈으로 본 어긋남이
> 우연이 아님을 **세 가지 통계로 검증**하고, 각 통계를 **정책 제안 하나씩**으로
> 연결하는 근거 페이지. 화면은 웹 `/evidence`, 탭 3개 + 하단 제안 밴드.
> **"솔루션"이라는 단어는 쓰지 않는다** — "진단의 근거와 제안".

## 왜 만들었나 (발표 서사에서의 역할)

- 심사 배점 중 **데이터 기반 문제해결(30점)** 대응 파트. 지도에서 보여준 관찰을
  "그래서 통계적으로 진짜인가?"로 한 번 눌러 확인하는 단계다.
- 세 탭은 각각 **질문 → 검정 → 수치 → 제안** 구조를 갖는다. 슬라이드도 같은
  순서로 만들면 화면과 1:1 대응된다.
- 정직성 원칙(STRATEGY §8): 리허설/본선 수치는 배지로 구분하고, 가설이
  기각되면 기각됐다고 말한다(탭 ③이 실제로 그 사례 — 아래 참고).

## 탭 ① 미배차 통계 — 시간대별 운행대수와 미배차 확률  `본선 확정치`

| | |
|---|---|
| **질문** | 미배차는 언제, 왜 몰리는가? |
| **데이터** | 본선 해운대 두리발 13개월(2025-03~2026-03) 접수 **43,891건** 전수 |
| **방법** | 접수 시각 기준 24시간대 집계. 미배차 = 배차 자체가 되지 않은 접수. 운행대수 = 배차~하차가 동시에 진행 중인 건수(차량 ID 미제공 → 하한 추정) |

**핵심 수치**
- 전체 미배차 **4,311건 / 43,891건 (9.8%)**
- **21시 미배차율 40.7%** (전체 평균의 4.1배) · 17시 26.0% · 22시 34.4%
- 동시 운행: 낮 피크(9시) 평균 **9건** → 21시 **0건 수준**으로 급감
- 월별 미배차율 **7.9~11.3%** — 특정 달의 사고가 아니라 13개월 내내 이어지는 구조
- 표본 100건 미만인 새벽 1·2·4시는 비율이 튀어 화면에서 미표시(각주 처리)

**슬라이드 메시지 제안**: "접수는 남아 있는데 차가 먼저 사라진다 — 저녁
시간대에 미배차가 몰린다" → **제안 1: 저녁 운행 재배치(증차·교대 조정)**

**Q&A 주의**: 미배차 정의에 '기다리다 취소한 건'이 포함되고 접수 직후 변심
취소도 섞여 있음. 운행대수는 실제 가용 차량 수가 아니라 동시 진행 건수 하한.

## 탭 ② 인프라 순효과 — 시설이 1개 늘면 방문이 얼마나 느는가  `리허설 적합치`

| | |
|---|---|
| **질문** | 어떤 시설을 어디에 먼저 보강해야 하는가? |
| **데이터** | 음이항 회귀(전역 5월, 리허설 적합) IRR × 본선 해운대 동별 월평균 도착 |
| **방법** | 동네 규모 효과를 오프셋으로 걷어낸 뒤 시설 1개당 방문 배율(IRR)을 추정, 그 배율을 각 동의 실제 이용량에 적용한 **명시된 근사** |

**핵심 수치**
- 충전소 IRR **×1.22** [95% CI 1.10–1.36, p=0.0002] · 복지시설 **×1.14** [1.05–1.24, p=0.0013] — 둘 다 CI가 1(효과 없음)을 완전히 벗어나 통계적으로 유의
- 해운대 **충전소 0개 동 9곳** (18개 동 중 절반)
- 예: 우3동(충전소 0개, 월평균 도착 109건) 충전소 +1 → **+24.3건/월** (CI 10.8~39.2)
- **0개 동 9곳 모두 +1이면 월 +144건** (범위 64~233건) — 정책 규모 headline 숫자
- 병의원은 IRR≈0.99(순효과 없음)라 화면·발표에서 제외 — 충전소·복지시설만

**슬라이드 메시지 제안**: "수요는 있는데 시설이 빈 동부터 +1" → **제안 2:
충전소 0개 동 우선 보강** (격차 동 우3동 −3.1%p·반여1동 −2.8%p와 교차 확인)

**Q&A 주의**: 관찰 데이터라 인과 단정 불가(연관성). IRR은 리허설 적합 — 본선
재적합 시 오프셋을 상가수→등록장애인 인구로 교체 예정. "+N건/월"은 리허설
IRR × 본선 이용량의 근사임을 화면 각주에도 명시해 둠.

## 탭 ③ 침묵 지역 — 외곽은 병원이 멀어서 안 타는가?  `리허설 적합치`

> **이 탭의 포인트: 가설을 세우고 검정해서 "기각"된 것을 그대로 보여준다.**
> 데이터를 결론에 끼워 맞추지 않았다는 정직성 근거로, 발표에서 오히려 강점.

| | |
|---|---|
| **질문** | 외곽 주민은 병원이 너무 멀어서 (두리발을) 안 타는가? |
| **데이터** | 전역 5월 데이터 중 목적='병원' 통행 **6,351건** (본선 해운대 데이터에는 출발 좌표·목적 컬럼이 없어 전역 기준 — 리허설 배지) |
| **방법** | ① 출발→병원 직선거리 구간별 미배차율 ② 출발동별 '병원행 평균거리 × 병원행 비중' 상관 검정 |

**핵심 수치 — 가설 기각의 근거**
- 거리 구간별 미배차율: 0–2km **4.9%** · 2–5km **5.7%** · 5–10km **4.5%** · 10km+ **4.8%** → 거리와 무관 (전체 5.0%)
- 동별 상관 **r = −0.003** (동 188곳, t=−0.04) → 병원이 멀다고 병원행 시도가 줄지 않는다
- 오히려 외곽 장안읍: 병원행 평균 **16.4km** 이동, 병원행 비중 **31%**(최상위), 미배차 0%

**슬라이드 메시지 제안**: "병원은 멀어도 타는 **필수 수요**다. 외곽의 문제는
'탑승 포기'가 아니라 **편도 10km+의 이동 부담**" → **제안 3: 거리 부담 완화**
(순회·거점 진료, 병원 셔틀 연계, 장거리 병원행 요금 지원)

**Q&A 주의**: 거리는 직선거리(운행경로 아님). 병원행 이동거리 중앙값 4.0km.
동별 산점은 전체 접수 30건 이상 동만 포함. '기타' 목적이 57%라 병원행이
과소집계됐을 수 있음(본선 재분류 대상).

## 하단 제안 밴드 (발표 09 슬라이드와 동일 구성)

1. **저녁 운행 재배치** — 소관 부산시설공단 · 21시 미배차 40.7%, 본선 미배차 4,311건/13개월
2. **시설 빈 동 우선 보강** — 소관 지자체·구청 · 충전소 IRR ×1.22, 우3동 −3.1%p·반여1동 −2.8%p
3. **외곽 거리 부담 완화** — 소관 지자체·공단 · 외곽 병원행 평균 16.4km, 좌4동 1천명당 9,542건

## 수치 통일 규칙 (문서·발표 공통 — 어기면 Q&A에서 깨짐)

- 본선 총계는 **43,891 접수 / 37,687 완료 / 미배차 4,311** 만 사용
- 전역 5월 총계는 37,512 접수 / 미배차 3,520 / 포기 추정 2,667건/월 (retry-funnel)
- 리허설(전역 5월)과 본선(해운대 13개월) 수치를 한 문장에 섞을 때는 반드시 출처를 병기
- IRR은 소수 둘째 자리(×1.22, ×1.14), 격차는 소수 첫째 자리(−3.1%p)
