# DIVE 2026 발표 QA

발표에서 과장 없이 빠르게 답하기 위한 공통 답변이다. 실제 본선 데이터로
교체한 뒤 숫자와 `리허설/확정` 상태를 마지막으로 다시 확인한다.

## 예상 대기시간은 실시간 예측인가?

아니다. 현재 화면은 2025년 5월 같은 시간대의 `접수→배차`와 `배차→승차`
중앙값, 출발지 미충족 비율, 휠체어 조건을 결합한 데모용 근사치다. 실제
운영에는 차량 GPS, 도로시간, 운전자 상태, 예약 큐가 추가로 필요하다.

## 배차 시스템이 실제 배차 결정을 내리는가?

아니다. 현재는 조건에 따른 대기·미배차 위험과 우선순위를 비교하는
의사결정 지원 시뮬레이션이다. 운영 배차를 자동 실행하지 않는다.

## AI 또는 LLM은 무엇을 하는가?

배차 점수와 우선순위는 규칙·통계 계산으로 결정한다. LLM은 계산 결과와
근거를 자연어로 설명하거나 질의응답하는 계층으로만 연결할 계획이다.
현재 데모에는 외부 LLM이 연결되어 있지 않다.

## ChatGPT를 Llama로 바꿀 수 있는가?

설명 계층을 OpenAI-compatible API 인터페이스로 분리하면 교체할 수 있다.
다만 현재 화면에서 Llama를 실제 사용한다고 주장하지 않는다. 연결과
검증이 완료된 모델만 발표에서 사용 모델로 밝힌다.

## 왜 미배차 위험이 높은가?

선택 시간대의 과거 미배차율과 출발 행정동의 미충족 비율을 함께 본다.
현재 점수는 우선순위 비교를 위한 휴리스틱이며 인과모형이나 운영 SLA가
아니다.

## 회색이거나 표시되지 않는 지역은 수요가 0인가?

아니다. 원자료가 제공되지 않았거나 표본이 부족한 지역일 수 있다.
각 레이어에 분석 범위를 표시하고, `0`과 `데이터 없음`을 구분한다.

## 개인의 이동 경로를 보여주는가?

아니다. 행정동, 250m 격자, 약 100m 반올림 셀처럼 집계된 단위만
표시한다. 개인 추적이나 재식별을 목적으로 하지 않는다.

## 사각지대 점수는 무엇인가?

행정동별 하차 수요, 인프라 수준, 미배차 수요를 표준화해 결합한
우선순위 지표다. 절대적인 복지 수준이 아니라 다른 지역보다 수요 대비
인프라가 부족한 곳을 찾는 용도다.

## 왜 도착 이후 400m를 보는가?

특별교통수단이 목적지에 도착해도 입구 턱, 층 이동, 내부 좌석,
장애인화장실이 없으면 실제 활동은 완성되지 않는다. 이동 성공과 목적
달성 사이의 마지막 접근성 사슬을 보여주기 위해서다.

## 어떤 결과가 실제 데이터이고 어떤 결과가 리허설인가?

운행 건수, 미배차, 취소, 대기시간, 행정동별 수요는 실제 공개 데이터
집계다. NB 회귀와 bootstrap 등은 실제 2025년 5월 데이터로 계산했지만
일부 노출변수가 대리변수이므로 `리허설`로 표시한다. 본선 데이터와 최종
변수로 다시 적합한 결과만 `확정`으로 바꾼다.

## 제안의 효과는 어떻게 검증할 것인가?

개선 전후의 미배차율, 대기시간, 목적지 400m 내 접근 가능한 선택지,
우선 사각지대 순위 변화를 같은 단위로 비교한다. 현재 `충전소 +K`
시뮬레이션은 방향을 비교하는 근사치이며 실제 설치 효과를 보장하지 않는다.
